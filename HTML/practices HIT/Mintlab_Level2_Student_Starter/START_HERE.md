# MINTLAB — Level 2 HTML Challenge

**Goal:** Rebuild the complete website content you see in `preview-desktop.png`, using HTML only.

You have already been given the finished website layout, CSS, and images. The CSS is not part of this assignment.

## What to do

1. Open `index.html` in VS Code.
2. Open `preview-desktop.png` to see the completed website.
3. Open `CONTENT_GUIDE.txt` to find the exact text and link destinations.
4. Add HTML inside the blank `<!-- ... -->` areas in `index.html`.
5. Do not delete or edit any existing wrappers, classes, IDs, image tags or the CSS file.
6. Preview your website in a browser. Check that links, bookmarks and the table work.
7. Submit your `index.html` file and a screenshot of the result.

**Important:** You are NOT asked to write CSS or to choose any CSS class names. All class names and layout containers have already been added for you. Choose your own HTML elements for the missing content; the guide intentionally does NOT tell you which tags to use.

**Topics to practice:** headings, paragraphs, text formatting, hyperlinks, bookmark links, absolute URL, lists, table, colspan, nesting.

**Suggested time:** 90–120 minutes.
